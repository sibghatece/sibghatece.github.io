Code

I release code so that the numbers in my papers can be checked and reused. All repositories are on GitHub.

BSPC_2026_Alzheimer_AstroPhys

Reproducible pipeline for EEG-based detection of Alzheimer's disease and mild cognitive impairment using astrophysics-inspired features and hybrid feature selection. Companion code for the 2026 paper in Biomedical Signal Processing and Control.

MATLAB

adhd-eeg-leakage-benchmark

Leakage-controlled benchmark of EEG-based ADHD classification across five public datasets. Nine feature families plus EEGNet, evaluated under subject-grouped nested cross-validation.

MATLAB

schizophrenia-eeg-leakage-free-benchmark

Leakage-free evaluation of class-conditional Tucker decomposition for schizophrenia detection from EEG, with subject-wise baselines on three public cohorts (RepOD, MSU and button-tone).

Python
